# Context and resume

For substantial work, Root keeps a compact record in a project-approved local artifact area: outcome, authority pointers, acceptance, ownership, completed/pending Goals, primary success signal, blockers, validation evidence and next action. This is working context, not a replacement specification system or a hook ledger.

On resume, read current user intent and project instructions, inspect live workspace/Git state without destructive repair, verify the relevant evidence inputs, invalidate only evidence whose inputs changed, and bind only pending work. A missing record or unavailable task is unknown, not complete. Do not repeat completed work or broad validation merely because the conversation resumed.

When Root or Astra needs wide factual exploration, formulate one bounded Scout question. The returned `RESEARCH_CAPSULE` is compressed into Goal pointers; a fresh sufficiently narrow map avoids duplicate reconnaissance.
